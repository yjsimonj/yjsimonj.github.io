# os 개발 공부 시작
- 계속 os를 공부해보고 싶었으나 자료가 너무 어려워 어디서 부터 배울지 모르겠었음. 그래서 오래 걸리더라도 처음부터 주요 기능들까지 구현하는 것을 목표로 빈폴더에서 시작함. xv6 소스코드를 레퍼런스 삼아 개발 시작.

# 한 내용
- entry.S, kernel.ld, types.h, param.h, riscv.h, start.c, main.c 등을 작성
- entry 에서 코어당 4096B 씩 할당. start 에서 처음 M Mode 상태에서 페이징 끄기, PMP 전체 허용설정 이후 S Mode 로 내려감. 이후 main 실행
